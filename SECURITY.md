# Security policy

Security reports are welcome for the latest source and current Windows beta. Older local builds and unverified platform behavior may require reproducing an issue on the current version.

Use **Security → Report a vulnerability** in this GitHub repository to report privately. Include the affected version, platform, reproduction steps using generated files, expected behavior and impact. Do not submit real private documents, credentials or personal library databases.

Folder containment, stale file identity, document-parser isolation, preview authorization and safe trash behavior are relevant areas. No guaranteed response or remediation timeline is currently offered.
