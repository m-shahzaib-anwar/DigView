- Validate Windows install/uninstall and upgrade with a disposable library.
- Validate import from an earlier app identity, preference retention and startup opt-in.
- Check each preview format and unsupported-codec fallback.
- Confirm cancellation, unavailable-folder recovery and reviewed trash behavior with generated fixtures.
- Establish macOS/Linux runtime evidence before advertising support.
- Configure production signing/update infrastructure only when explicitly ready to publish it.
